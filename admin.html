Configurar GoatCounter
Para ver estadísticas necesitás una cuenta gratuita en goatcounter.com. Una vez creada e instalado el script en las páginas, ingresá tu Site Code (lo que va antes de .goatcounter.com) y un API Token (Settings → API tokens → Create new token → marcar "Read statistics"). Se guarda en tu navegador, no se transmite a ningún servidor.
